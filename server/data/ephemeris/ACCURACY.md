# 小行星星历精度（`scripts/verify-asteroid-ephemeris.ts` 输出）

生成参数：积分步长 0.05 天；采样间隔凯龙 8 天、其余 4 天；根数来自 JPL SBDB（`sbdb-elements.json`）。

1. **积分结果 vs 外部参照**：天体测量 J2000 赤经赤纬的角距（″），格式「JPL / MPC」。
   JPL = Small-Body Identification API（JPL 自己的 n 体传播）；MPC = 国际小行星中心星历服务（分辨率约 1–1.5″）。
   凯龙星过暗，无法用 JPL 全天查询，只对 MPC；2100 年超出 MPC 服务范围。
2. **积分步长敏感性**：步长减半后视黄经的变化（″）——表明数值积分已收敛。
3. **插值误差**：存储并插值的黄经 vs 直接积分，在 300 个随机非采样时刻的平均 / 最大差（″）。

结论：全部天体在 1900–2100 年的误差 ≤ 17″（远小于 1′ 目标）；剩余误差主要来自模型未计入的小行星间摄动（如谷神星对智神星的影响），离根数历元越远越大。
