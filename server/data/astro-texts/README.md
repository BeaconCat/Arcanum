# 星盘解读文案库（astro-texts）

## 原创声明

本目录全部文案均为天枢 Arcanum 项目**原创撰写**的中文内容，依据的是西洋占星中行星、星座、宫位、相位的通用象征意义，
没有复制、翻译或改写任何第三方 App、网站或书籍的具体文字。可随项目自由修改与再利用。

写作原则：温和、具体、有建设性；避免宿命论与绝对化判断；外行星落星座按"世代特质"描述。

## 文件结构

每个 JSON 文件形如：

```json
{ "category": "sign", "entries": { "sun.0": { "k": ["关键词"], "t": "解读正文", "a": "建议（可选）" } } }
```

同一 `category` 可以分散在多个文件里，加载时按类别合并（见 `server/services/astro-interpret.service.ts`）。

| category    | key 格式                          | 说明 |
|-------------|-----------------------------------|------|
| `sign`      | `{body}.{0-11}`                   | 太阳…冥王、北交点、凯龙、上升(`asc`)、天顶(`mc`) 落星座，0 = 白羊 … 11 = 双鱼 |
| `house`     | `{body}.{1-12}`                   | 太阳…冥王、北交点、凯龙落宫；莉莉丝、福点、谷神、智神、婚神、灶神为简短版 |
| `body`      | `{body}`                          | 北交点、凯龙、莉莉丝、福点、四小行星的总体象征 |
| `aspect`    | `{a}.{b}.{conj\|harm\|tens}`      | 本命相位，a/b 按 日月水金火木土天海冥升顶 顺序；`minor.{type}` 为 6 种次要相位的通用文案 |
| `pattern`   | 见文件                            | 大三角(按元素)、大十字/T三角(按模式)、风筝、上帝之指、神秘长方形、星群 |
| `synastry`  | `{a}.{b}.{conj\|harm\|tens}`      | 比较盘接触，日月水金火木土升两两组合（含同名），措辞为"一方的X与另一方的Y" |
| `synHouse`  | `{body}.{1-12}`                   | 对方的日月金火木土落入你的宫位 |
| `composite` | `sign.{body}.{0-11}` / `house.{body}.{1-12}` | 组合盘日月金升落星座、日月金落宫（关系视角简短版） |
| `transit`   | `{outer}.{natal}.{conj\|harm\|tens}` | 行运木土天海冥 × 本命日月水金火升顶 |

`conj` = 合相；`harm` = 和谐（六合、拱）；`tens` = 紧张（刑、冲）。

## 长度约定

正文 60–140 字；简短类（莉莉丝/福点/小行星落宫、组合盘）30–110 字。
